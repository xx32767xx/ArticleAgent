> 主题：项目**决策**——决定了什么、为什么、备选方案、影响。只追加，不覆盖；决策被推翻时新增一条并把旧条目标记"废弃"。
> 内容边界：接口字段与状态机去 `docs/347模块接口与交互规范-v0.2.md`；平台事实去 `docs/平台调研-Codar插件体系.md`；本文件不记录这两类内容。

## ADR-001 任务范围为图片结构总览的 3、4、7 三项

- **状态**：已定
- **背景**：团队分工依据《结构总览》功能规划表（编号 1、3、4、5、6、7，OCR 确认无 2）。
- **决策**：本组负责 **3 论文辅导智能体、4 论文检测智能体、7 导师反馈落实追踪**。
- **依据**：与需求文档 M4 讲解型/检测型辅导、M5 导师指导与评语、M9 留痕对应。

## ADR-002 职责隔离，模块间以接口调用交互

- **状态**：已定
- **背景**：讨论确定"职责之间的隔离设计"：辅导只负责指导、检测只负责评价、追踪负责过程记录。
- **决策**：
  1. **3 辅导**只指导，辅导时通过接口调用 4 获取当前论文评价结果（`inspect.query_latest`）；不自己做评价。
  2. **4 检测**只评价（问题清单/评分），不指导、不代写。
  3. **3/4 每次运行都调用 7 的接口**上报过程记录；**7 是过程记录的唯一写入方**（哈希链事件流 + 待办状态机 + 复核统计）。
  4. 依赖单向无环：3 → 4（只读评价）、3/4 → 7（只写记录）。
- **影响**：接口契约以"调用方驱动"方式定义；7 必须同时承担记录服务与追踪服务两个角色。

## ADR-003 接口契约以 v0.2 规范为准

- **状态**：已定（评审中，文档见 `docs/347模块接口与交互规范-v0.2.md`）
- **决策**：统一 Context 对象 + 三类请求/响应契约（`coach.*` / `check.*` / `inspect.summary` / `feedback.board`）+ 状态机 + `EvidenceEvent` 事件契约 + 错误码表。
- **说明**：契约变更须单独评审并同步 fixtures 与契约测试。

## ADR-004 单仓库（monorepo）开发

- **状态**：已定
- **背景**：4 人团队、模块强契约耦合、最终交付为一个插件包。
- **决策**：一个仓库承载契约包（`contracts/`）+ 三个 Skill 目录 + `rulepacks/` + `servers/tracker/` + `tools/devkit/`（桩）+ CI。
- **备选**：多仓库（被否：版本对齐成本高、契约漂移风险大）。
- **影响**：按目录 CODEOWNERS 认领；契约改动单独 PR。

## ADR-005 契约测试 + 桩先行 + 两层 CI

- **状态**：已定
- **背景**：开发时对方模块接口可能尚未实现，需要各模块独立可测。
- **决策**：
  1. `contracts/` 存放 JSON Schema（合同）+ fixtures（黄金语料）+ 契约测试；
  2. `tools/devkit/stubs` 提供假接口，桩和真实现跑同一套契约断言；
  3. CI 两层：每次提交跑"单测 + 契约对桩"（快、离线）；合并前/夜间跑"契约对真实现 + 集成（AC-02/06/09）"。
- **影响**：接口兼容性问题在合并前暴露，不依赖联调日。

## ADR-006 交付形态为三个独立 Skill，后续可打包为 Plugin

- **状态**：已定
- **决策**：首期交付 `paper-coach`（3）、`paper-inspector`（4）、`advisor-tracker`（7）三个 standalone Skill；后续再打包为 `paper-writing-coach` Plugin 上架 SpeedSkills。
- **依据**：Skill 格式通用（SKILL.md）、可独立发布迭代；Plugin 打包属增强。发布需管理员渠道（平台暂未开放第三方自助发布）。

## ADR-007 文档按主题拆分

- **状态**：已定（2026-11）
- **背景**：交接与人工阅读需要单一职责的文档，避免"一份文档什么都有"。
- **决策**：
  - `docs/决策记录.md`（ADR，只追加）——本文件
  - `docs/347模块接口与交互规范-v0.2.md`——接口契约正文
  - `docs/平台调研-Codar插件体系.md`——平台事实（事实变化才更新）
  - `docs/reference/`——外部/原始材料（不改写）
  - `docs/交接说明.md`——**只做导航与索引**，不承载内容
- **影响**：每次重要决策只更新对应主题文档；导航文档保持稳定、简短。

## ADR-008 远程仓库由负责人管理，AI 仅 commit

- **状态**：已定
- **决策**：AI 只负责本地仓库的 `git add/commit`；`remote` 配置、`push`、GitHub 侧管理由团队负责人完成（沙箱环境下不能 push）。
- **影响**：AI 提交后不检查远程状态；如需推送由负责人执行。

# 论文智能辅导平台（347 部分）· Codar 插件开发

> 本组负责「科技论文智能辅导平台」需求文档中 **图片结构总览的 3、4、7 三项**，以 **Codar（科搭）插件（Skill/MCP）** 形态交付：
> - **3 论文辅导智能体**：讲解型辅导（教你怎么写，不替你写）—— 丙
> - **4 论文检测智能体**：检测型辅导（查问题、给依据、可复检）—— 甲、乙
> - **7 导师反馈落实追踪**：过程记录 + 待办状态机 + 复核（全部留痕）—— 丁

## 快速开始

**新会话 / 新成员请按顺序读：**

1. `docs/交接说明.md` —— 入口、进度、待办（**先读这个**）

## 协作约定

- 个人空间 `members/<代号>/`：独立开发 + 个人文档，**入库但非交付物**，公共代码不得依赖。
- 公共区：契约 `contracts/` 改动走 2 人评审；决策进 `决策记录.md`；接口变更进接口规范。
- 分支：`main` 受保护、个人常驻分支 `dev/<代号>`、特性分支可选；不直接 push main。详见 `docs/协作规范.md`。
- 临时文件放 `temp/`；提交只做 commit，推送与远程由负责人管理。
